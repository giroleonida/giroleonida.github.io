Política de privacidade

Última atualização: 18/10/2026

Esta política descreve como o site Giro Leonida e o aplicativo Giro Leonida Publisher ("o App"), operados pelo canal Giro Leonida (contato: giroleonida@gmail.com), tratam dados.

1. Para que serve o App

O App é uma ferramenta interna, usada somente pela equipe do Giro Leonida para enviar e agendar vídeos e imagens nas contas oficiais do próprio Giro Leonida no YouTube, TikTok e Instagram, e para consultar estatísticas públicas e de desempenho dessas contas. O App não é disponibilizado ao público.

2. Dados acessados pelo App

  • Tokens de autorização (OAuth) das contas do Giro Leonida, concedidos pelo titular dessas contas;
  • Informações básicas das próprias contas do Giro Leonida (nome do canal, ID) e métricas dos vídeos publicados (visualizações, curtidas, comentários);
  • Os arquivos de mídia produzidos pelo próprio canal, enviados para publicação.

O App não coleta dados de outros usuários, espectadores ou terceiros, não vende dados e não usa dados para publicidade.

3. Armazenamento e segurança

Os tokens ficam armazenados localmente, em computador controlado pela equipe, com acesso restrito. Nenhum dado é compartilhado com terceiros, exceto o envio do conteúdo às próprias plataformas (YouTube, TikTok, Instagram) no ato da publicação.

4. Uso das APIs

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O App usa os Serviços de API do YouTube; ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

5. Revogação e exclusão

O titular pode revogar o acesso a qualquer momento em myaccount.google.com/permissions (Google/YouTube) ou nas configurações de apps autorizados do TikTok e da Meta. Para solicitar a exclusão de dados armazenados pelo App, escreva para giroleonida@gmail.com; os dados são apagados em até 7 dias.

6. Visitantes deste site

Este site é estático, hospedado no GitHub Pages. Não tem cadastro, formulário, cookies de rastreamento nem anúncios. O provedor de hospedagem pode registrar dados técnicos de acesso (como endereço IP e navegador) para segurança, conforme a política do GitHub. Os vídeos incorporados do YouTube usam o modo de privacidade aprimorada (youtube-nocookie.com). A página do mapa incorpora um post do Reddit, que pode usar cookies próprios conforme a política do Reddit. Pela LGPD, você pode pedir acesso, correção ou exclusão de qualquer dado seu pelo e-mail abaixo.
